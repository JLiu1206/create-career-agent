# create-career-agent

Installs the [career agent template](https://github.com/JLiu1206/career-agent-template)
for Claude Code: draft internship, graduate scheme, placement and research
applications from your own facts, in your own voice.

## Install

With npx (macOS, Windows, Linux; needs Node 18+ and git):

```
npx create-career-agent my-career-agent
```

With Homebrew (macOS, Linux):

```
brew install jliu1206/tap/career-agent
career-agent my-career-agent
```

Either one copies the template into `my-career-agent/` and starts a fresh git
history with no link back to the public template, so your CV can't be pushed
there by accident. Then:

```
cd my-career-agent
claude
/career-setup
```

See the [template README](https://github.com/JLiu1206/career-agent-template#readme)
for what it does and how to use it.
